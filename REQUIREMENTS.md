# Requirements - learn-git

1. The repository is a small sandbox for practising git commands and workflow, where mistakes cost nothing.
2. It contains `README.md` (notes on the git commands that were run) and `test_main.py` (a small `calc` class with `add` and `multiply`).
3. It has two branches, `main` and `dev`, and a remote on GitHub (`muzaffer01/learn-git`) over SSH, with both branches pushed.
4. Practice goals are tracked on the project dashboard: what has been practised (init, commit, branch, push) and what is next (merge, pull request, conflicts, undo, stash, rebase, tags).
5. Dashboard pages are kept locally and are not tracked on git.
6. Dashboards and display pages use light, high-contrast color coding for labels, tabs, filters and statuses on dark backgrounds, with darker variants in light mode (standing rule, 2026-10-01).
